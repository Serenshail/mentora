# Mentora 微信小程序端

与 [mentora 网页版](https://mentora-orpin.vercel.app) **同一产品、同一后端、同一份云端数据**的原生微信小程序形态。账号互通：网页端注册（需内测邀请码），小程序直接登录。

## 用微信开发者工具打开

1. 打开微信开发者工具 → 导入项目 → 目录选本目录（`miniprogram/`）
2. AppID 填你在 mp.weixin.qq.com 注册的小程序 AppID（没填也能用「测试号」先跑）
3. 详情 → 本地设置 → 勾选 **「不校验合法域名」**（开发阶段必需，后端域名还没有备案）
4. 编译即可。登录用网页版同一账号

## 功能范围（V1.0）

- **登录/注册**（激活码通道，一人一码，与网页版一致）
- **总览**：进行中目标 + 今日任务直达、到期复习数、学习热力墙（12 周）、连续天数
- **学习教练**：引导页（苏格拉底轻引导 → 目标卡 → 总纲要生成）→ 目标列表 → 阶段天目录（一键生成）→ 今日页完整闭环：单日细节展开（目录占位 → 资料/方法/验收）→ 讲义生成（流式，6 段教学模板）→ 资料（复制链接）→ 答疑（教练流式）→ **验收判分**（证据强制：判分不引用讲义原文自动降级）→ **迁移题真门**（过了判分还要答迁移题才解锁下一天）→ 强制跳过（输入「跳过」确认）
- **第二大脑**：笔记列表/搜索/文件夹筛选 → 笔记阅读（markdown 渲染、出链/反链跳转、掌握状态）
- **复习**：到期队列 → 复习官从笔记原文出题（流式）→ 判卷（必须引用原文，无证据改判 fail）→ FSRS 兼容的经典 1/3/7/15/30 档调度
- **读书伙伴（阅读系统 V1.0）**：书架 → 新书建档（搜索核实真实性，三态弹窗与 Web 同判据）→ **认知地图**（四区域概览）→ **阅读目标**（AI 推荐四成果，可改）→ 五模式对话（苏格拉底/费曼/碰撞/精读/复盘，模式切换开场协议同网页版）→ **三重验收**（理解/结构/迁移三题，四级判定，全过=节点掌握 + 学习证据）→ **沉淀**（七类一句话 + 节点小结入第二大脑）→ **整本五态**（未开始/阅读中/已读完/验收中/已掌握）
- **人生伙伴**：12 人物 + 4 认知工具席位单聊；**圆桌会议**（推荐 3 席，全员逐席发言 → 主持人七节纪要）

## 与网页版的有意差异（诚实边界）

- 复习调度用经典间隔档（不写 `fsrs` 字段）；网页端 FSRS 会按 `reviewStage` 预热无缝接管，两端数据互相兼容
- 教练答疑/读书对话暂不注入第二大脑 RAG 证据（`ragCtx` 为空，网页端体验完整）
- 知识迁移任务/独立复检、结业回路（目标+整本）、策略推荐、加节点、路线重排、阶段重排：在网页端完成，数据互通
- 流式断连处理：与服务端契约一致（必须收到 `t=end` 才算完整回答），半截内容按失败保留并提示
- 断流/超时/配额文案如实透传服务端（每日 AI 调用配额 60 次与网页版共享）

## 工程说明

- 数据层 `utils/store.js`：复刻网页版 zustand store 的关键写路径（过门/真门/解锁链/MOC/双链解析/复习档），改动后 2.5s 防抖推云 + onHide 强制 flush；登录时云端为准，云端空快照绝不覆盖本机（防「空快照覆盖」历史事故）
- 流式 `utils/chat.js`：`wx.request enableChunked` + `utils/utf8.js` 增量 UTF-8 解码（处理汉字/emoji 半包），NDJSON 协议与网页版逐字一致（`t:d/h/e/p/end`）
- 判分 `utils/grade.js`：网页版 zod schema 的宽容解析移植 + 证据强制降级
- 后端配套：`/api/sync` GET 支持 `?plain=1` 明文快照（小程序解不了 x-gzip），见 `src/app/api/sync/route.ts`
- 图标：`scripts/gen-mp-icons.mjs` 零依赖生成；核心逻辑冒烟：`node scripts/smoke-mp-core.cjs`（32 断言）

## 已知限制

- 编译验证依赖开发者工具：服务端口未开启时 CLI 不可用（工具 → 设置 → 安全设置 → 服务端口）
- `wxml` 未经过编译器验证的语法风险由导入时编译兜底；页面 JS/WXSS 已过 node --check 与逻辑冒烟
