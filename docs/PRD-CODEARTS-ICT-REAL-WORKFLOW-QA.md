## 3. P0 单浏览器同步误报与数据完整性

复现：在独立本地环境用一个浏览器上下文和一个标签页登录。等初始同步完成。首页发一条长问答，在消息生成时点停止，再发「只输出数字：9 乘以 7 等于多少？」。待结束后刷新，依次访问学习与笔记库。另做一轮只创建笔记、编辑、等待同步、刷新。记录页面是否出现「另一台设备已更新」，对照实际上有几个会话、请求和写入。

采证：为每一步记录 GET/POST 的时间、状态、baseVersion、uploadId、服务端 currentVersion/currentUploadId、客户端本地编辑版本、待同步标记与 UI 状态。禁止记录令牌、密码、请求正文的私人数据。区分「真 409」「成功回执未被接收」「仅客户端产生冲突状态」「尚未复现」，不要靠关闭横幅消除症状。

验收：

1. 同一浏览器重复跑至少三次。正常发问、取消、再发、刷新、建笔记和编辑后，内容可读，没有无依据的跨设备横幅。
2. 人为引入同账号两个独立浏览器并发修改，真正冲突保留提示与本机未写入数据，获胜方能重新加载。不能因消除误报覆盖他端新版本。
3. 首次写入、丢回执原样重试、回执到达前再编辑、仅缺旧客户端字段、断网后恢复都逐项检查。重试上限和数据保留规则继续符合原 PRD；HTTP 返回与最终对象都要查。
4. D1 只有确认独立测试实例后才运行，不使用生产权限替代。未能跑 D1 时记录阻塞并保留其他通道现有行为。用实际 PostgreSQL 验证 RDS 本地对等场景，标 local-equivalent。

## 4. P1 圆桌点名、身份和长等待

复现：新建 Naval、Jobs、Taleb 圆桌，问「每周只有三小时，学 Python 先做项目还是先看课？」观察三席与主持。完成首轮后输入「这轮只请 Naval 回答，其他席位不要发言。把刚才建议压缩成第一天的一个动作」。检查每个真实聊天请求的 mode、personaId 和最终卡片。另从人物列表开独立 Naval 单聊，连续追问两次并刷新。

验收：

- 普通圆桌保留全员发言和主持纪要。定向追问须提供明晰的选人入口，并识别明确、唯一的点名表达。目标唯一时只发目标席位，不发其他席位，也不默认发主持。沿用这张圆桌的相关上下文。歧义时先让用户选。保留原参会名单和会话历史。
- 不把张冠李戴的正文当作通过。验证卡片身份、请求身份、回答身份一致。独立单聊和圆桌内单席是不同用例，都要测。
- 单席失败、主持超时、取消和切会话，都要有可解释的终态。完成的回答保持可读。重试只重试失败部分。分别记录开始时间、首段、结束、取消、终态和耗时。观察长等待期间真实进展，验证恢复可用。

## 5. P1 视频检索、来源和资料质量

复现：首页输入「请联网找两个可在 B 站直接播放的中文 Python CSV 入门视频。只要具体视频链接，不要文章、文档、站点首页或搜索页。找不到就直说」。在学习计划资源入口用同一约束再测一次。补测「不要视频，只要官方文档」「找不到符合条件的视频」和「要求中文入门、链接看似视频但不相关或无法打开」。

验收：

- 视频类型、语言、难度、主题和平台由候选与核验结果确认。结果只展示符合用户硬条件的条目。达不到数量时只给符合条件的项；没有时明确找不到，列出可选放宽项由用户决定。
- 区分具体视频页可确认、页面可打开、正在浏览器实际播放三种证据。在隔离浏览器逐条打开，检查标题、内容主题与播放结果。播放没有成功时明确标注，不能因为 URL 有 BV 或 HTTP 200 就声称可播放。
- 每条推荐和来源一一对应，标题和来源来自实际核验过程。来源区不混入无关首页、搜索页或不同平台。记录请求轮数、候选数量和耗时，避免无意义地反复搜相同词。

## 6. P1 思考状态与回答质量

思考状态复现：长问答发出后截图记录等待、实际工具、正文开始、完成。再测试用户立刻停止、已经流出部分内容后停止、模拟断流、真实上游空输出、刷新及切会话。仅用实际事件、可公开的工具进度及供应商明确提供的公开摘要展示状态。不展示私有思维链，不编造正在执行的工具或阶段。

验收：可见状态对应实际事件。用户停止显示已停止并能继续；空响应、上游错误、断流各自可辨。正文与工具过程分开；已生成的正文和可恢复的草稿按当前产品语义保留。切换会话时不会串流，也不会把过期结果写进另一会话。记录每个阶段耗时并注明哪些来自可控故障测试。

回答质量复现：问「解释 Python 列表迭代时删除元素，用 [1,2,2,3] 示范」。检查主例、正确写法、边界例和自测输出；另固定自测代码 [1,2,3,4,5,6] 中逐项删除偶数，实际输出 [1,3,5]。补测简答「只输出数字：9 乘以 7」、多轮约束改口、对已有学习记录的事实检索、无证据时的诚实说明。

验收：示例能独立运行，解释与实测输出一致，简答遵循格式，多轮遵守最新约束，引用与结论匹配。每类用固定输入至少重跑两次，保存失败样本和模型标识。内容、事实、资源类型、引用强度和迟延分别记录，避免只报一个平均分。
