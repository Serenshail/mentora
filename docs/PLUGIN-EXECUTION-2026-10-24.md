## 1. 渠道定位

Obsidian 插件 `vault-home` 是**本地知识库与学习闭环的桥**，不是第二套产品：

- 默认入口是原生 ItemView 学习台（总览 / 学习教练 / 读书伙伴 / 人生伙伴 / 学习人生 / 设置）；
- `mentora:` 链接全部走原生视图；网页内嵌（webview）只作为显式「备用」命令保留；
- **不提供独立的第二大脑页面**（用户决策，`/brain` 回总览）；知识产物写成 vault 真笔记，
  关系图谱用 Obsidian 原生图谱。

它服务于主 PRD 的「一个入口」原则：主智能体在 Web 侧做意图路由，插件侧提供
**同一套方法论在本地数据上的落地**，以及首页仪表盘作为"今天做什么"的可见面。

## 2. 数据边界

| 数据 | 位置 | 是否随 vault 同步 | 备注 |
|------|------|------------------|------|
| 仪表盘内容（待办/习惯/快捷入口/索引） | `_home/data.json` | 是 | 用户手工维护，改完自动刷新 |
| 学习台状态（目标/书/会话/复习/活动） | `_home/mentora-store.json` | 是 | 自动生成；读坏时只读保护 |
| 知识产物（知识点/讲义/随手记/洞见） | `Mentora/` 下的真笔记 | 是 | 不写 frontmatter，避免污染与冲突 |
| 工具凭据（开放令牌/后台密码/训记 Key） | 插件设置 `data.json` | **不应外发** | 只在设​​置页填写，不写进内容文件 |
| 模型 Key（BYOK） | 插件设置 `data.json` | **不应外发** | 只存本机；不写入仓库/文档/日志 |

原则：**内容可同步，凭据不同步**。任何"把 Key 写进 vault 里的文件"的方案都不接受。

## 3. 日界与时区

- 插件：`MT_NOW(tz)` 用 IANA 时区（设置项 `timeZone`，默认 `Asia/Shanghai`）；
- 服务端：`/api/open/plan` 用 `MENTORA_OPEN_TZ`（默认 `Asia/Shanghai`）；
- 两端必须一致，否则「今日任务 / 到期复习」会错一天。
- 存量日期字符串按原日解释，**不做隐式平移**（避免历史记录跳变）。

验收：把系统时间拨到东八区 23:59 与 00:01，插件与服务端返回同一个 `today`（自动化 + 人工实测）。

## 4. 原生学习台的正确性契约

| 契约 | 要求 | 回归锁 |
|------|------|--------|
| 聊天发送 | 只有 `chatPane({onSend})` 一套入口；返回 `send()/isBusy()/setBusy()` | smoke：发送走 onSend / busy 拒绝重复 / 结束后复位 / 无 onSend 不静默 |
| 结构化输出 | `mtExtractJson` 与产品 `client.ts extractJson` 同算法（围栏 → 原文最早候选 → 裸文本） | smoke：裸数组 / 多候选 / 字符串内括号 / 不可解析 |
| 状态存储 | `mtStoreLoad` 返回 `{store,status,error}`；`error` 时只读 + 提示 + 禁止覆盖 | smoke：首次为空 / 往返 / 坏 JSON / 字段类型错 |
| 门控 | 验收不过不解锁；迁移题不答不解锁；跳过两击确认且留痕 | smoke：day passed / pendingUnlock / 解锁断言 |
| 版本一致 | 产物 banner 带 `BUILD-HASH`；vault 与工作区镜像字节一致 | `build.js --check` |

## 5. 发布门禁（插件侧，每次发版逐条勾）

1. `node plugin-src/build.js`（唯一真源 → vault + 工作区镜像）
2. `node plugin-src/build.js --check` 通过（产物新鲜）
3. `node test/all.js` **八层全绿**：
   产物新鲜度 / 凭据扫描 / 仪表盘渲染 / 训记 / Mentora 接入 / 插件生命周期 / 原生 smoke / 视觉门禁
4. `secret-scan`：源码、产物、测试输出、文档无真实凭据形态
5. `mentora-shot.js` 截图人工过一眼（五模块 + 设置 + 圆桌）
6. 生产冒烟：`/api/open/plan` 401/200、`/api/admin/overview` 401/200
7. 回滚：保留上一版 `main.js`（`BUILD-HASH` 可比对）；数据回滚走云端快照版本
