# Mentora 网页端 PRD｜笔记库入口与学习导航

2026 年 11 月 21 日 · 待实施

## 1. 用户目标

用户在学习教练和读书伙伴之间切换时，始终能在学习工作台右上角看到并打开同一个「笔记库」入口。模式切换区只负责切换两个模式。用户查完笔记后，可以回到刚才的学习或阅读位置继续。

本次范围为 Mentora 网页端，含桌面与手机浏览器。实施覆盖学习教练首页、读书伙伴书架、学习引导与计划详情、图书详情，以及笔记库返回路径。小程序不纳入本次验收。

## 3. 产品要求

### 3.1 页头与布局

```text
学习工作台页头
学习                                              [ 笔记库 ]

模式切换    [ 学习教练 ]  [ 读书伙伴 ]

当前模式的内容                                    [ 内容操作 ]
```

- **NAV-01｜独立入口。** 两种模式共用同一个页头。右侧保留一个带完整文字「笔记库」的操作，位置、样式与可点击区域一致。左侧标题可提供当前页面上下文，标题折行时不得挤占右侧入口。模式切换只更新选中项与下方内容。
- **NAV-02｜导航层级。** 学习教练和读书伙伴是切换栏里的两个选项。桌面侧栏、手机网页底栏与「更多」菜单移除笔记库导航项，并重新分配底栏空间。「添加书籍」「开始引导」等操作放在各自的内容区。全局搜索结果、笔记引用与直接链接继续正常导航。
- **NAV-03｜详情继承。** 从学习引导、学习计划详情或图书详情进入笔记库时，入口仍位于该页面页头右侧。原有返回、页面标题和业务操作各有位置。笔记库保持独立页面，详情页内可继续通过已有的「查看笔记」打开对应笔记。
- **NAV-04｜窄屏。** 320 CSS 像素起仍显示完整「笔记库」，点击区域至少 44 × 44 CSS 像素。窄屏允许标题折行、模式切换另起一行。入口须可点击、可用键盘到达并显示焦点。页头不能被侧栏折叠按钮或手机网页顶部栏遮挡。

### 3.2 进入、返回与兼容

- **NAV-05｜原位继续。** 点击右上角入口，在当前标签页打开笔记库。从笔记库点页内返回或使用浏览器后退，都能回到实际来源。来自书架时恢复读书伙伴及此前筛选、搜索和滚动位置。来自计划或图书详情时恢复当前对象和正在查看的步骤。切换模式或往返笔记库时，已保存的内容、进度以及已有本地保存的草稿继续可用。
- **NAV-06｜旧链接与引导。** 刷新时按页面地址恢复模式。旧书架地址 `/read` 仍进入读书伙伴，笔记库地址 `/brain` 和直达具体笔记的链接仍有效。直接打开笔记库且无来源时，页内返回默认进入学习教练。新手引导高亮实际可见的右上角入口，并保持原有学习教练与读书伙伴引导可用。
- **NAV-07｜关系链回归。** 打开一篇有关系链的长笔记，在正文阅读区内上下滚动时，关系链保持在正文上方可见。窄屏要能操作链上的条目，正文与顶部操作仍可使用。这条延续既有要求，当前源码已有独立正文滚动区，实际显示需在浏览器复验。

## 4. 验收清单

使用真实测试账号，准备一条进行中的学习计划、一本在读图书和一篇有关系链的长笔记。另用空数据状态检查入口是否受加载和空态影响。涉及引导生成或读书问答的恢复用例使用线上模型。主要用例在部署后的网页版本重跑，记录构建版本、浏览器、视口和实际结果。

| 用例 | 操作 | 通过标准 |
| --- | --- | --- |
| A01 模式切换 | 在同一窗口和滚动起点反复切换学习教练与读书伙伴，分别截图。 | 两张截图中笔记库保持同一页头、同一右上角位置与相同样式。切换区始终只有两个模式。 |
| A02 独立入口 | 展开和折叠桌面侧栏。用手机网页查看底栏和「更多」。切到读书伙伴并点「添加书籍」。 | 全局导航没有重复项或空槽。笔记库与添加书籍各有明确位置，关闭弹窗后入口仍可用。 |
| A03 响应式 | 桌面以 1440 和 1024 CSS 像素宽检查，再检查 125% 和 200% 浏览器缩放。手机浏览器检查约 390 和 320 CSS 像素宽。 | 入口文字完整，位置稳定，页面无横向溢出，模式按钮和页头操作均可点击。桌面可用键盘到达入口，焦点清晰。 |
| A04 书架往返 | 进入读书伙伴，设定筛选和搜索，滚动列表后打开笔记库。分别用页内返回与浏览器后退。 | 两种返回方式均回到原书架，模式、筛选、搜索与滚动位置可继续。 |
| A05 详情往返 | 分别从学习引导、计划详情和图书详情打开笔记库后返回。对已有对话刷新后再继续一轮。 | 入口都位于右上角。回到同一计划、图书或引导会话，已保存内容存在，能够继续原步骤。 |
| A06 刷新与兼容 | 刷新两个模式的页面，访问旧书架地址与笔记深链接，重新走一遍新手引导。 | 刷新恢复正确模式。旧地址到达预期页面。引导准确指向右上角入口，搜索与引用仍可打开对应笔记。 |
| A07 空态与异常 | 用空书架、空计划、数据加载中和加载失败状态切换模式并尝试打开笔记库。 | 每种状态下入口的可见性和位置一致。笔记库可独立打开，并展示自身的加载、空态或错误状态。 |
| A08 关系链 | 在桌面和手机网页打开具备关系链的长笔记，滚动正文，点击链上条目并返回。 | 滚动时关系链留在正文上方。关联笔记打开正确，窄屏可操作且无覆盖。 |

位置跳动、入口消失、重复出现、点击无效和返回错位均为本次发布阻断项。每项缺陷记录出现页面、前置状态、操作步骤与截图或录屏。修复后重走失败场景，并与另一个模式的对应路径交叉复验。
