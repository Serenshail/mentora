# 手机与电脑适配修复 · 2026-11-16

本批直接修改现有网站，保留核心业务。针对长标题、长英文、平板与较小电脑窗口、横屏短视口、键盘挤压可视区域复现问题后修复。

## 已修复

| 场景 | 修改前 | 当前行为 |
| --- | --- | --- |
| 成长记录长标题 | 320px 视口的页面被撑至 1628px | 共享 Card 允许收缩，长内容留在卡片内 |
| 学习目标卡片 | 320px 标题和 768px 元数据越界 | 标题可断行，窄内容区采用纵向层次 |
| 设置页 | 768px 视口的内容伸至 961px，“保存”按钮跑出屏幕 | 小电脑窗口用横向栏目选择、纵向表单；宽电脑窗口再展示侧栏布局 |
| 笔记工作台 | 1024px 窗口仍强行三栏，标题输入仅约 10.8px 宽 | 根据工作区自身宽度切换单栏/三栏；同场景标题约 533.9px 宽 |
| 笔记来源链接 | 窄屏打开指定笔记仍可能停在列表页签 | 选中不同笔记时进入内容页签，随后手动切回列表保持有效 |
| 阅读详情 | 超长章节 Badge 撑大页面，320px 页面伸至 1052px | 徽章可收缩换行，正文网格使用 minmax(0,1fr) |
| 书架首屏 | 超长书名、章节名占用过多高度；重复学习页标题 | 标题摘要限行且保留完整 title/链接名称，读书页独立页头 |
| 共享弹窗、搜索 | 使用布局视口高度，键盘弹出后底部内容可能被挡 | 使用 visualViewport 高度与偏移，内部滚动，退出/提交仍可操作 |
| 助手面板 | 键盘可见区域内输入框或关闭按钮不可达，顶栏可盖住面板 | 高度与位置随可见区域调整；面板层级高于导航、低于模态弹窗 |
| 手机表单 | 部分共享表单字号较小 | 窄屏共享 Input/Textarea 及搜索、助手输入使用 16px；不禁用页面缩放 |

visualViewport 仍由已有共享 hook 管理，卸载清理变量；不在 pinch zoom 时改动弹层几何。没有新增依赖、迁移数据或部署。

## 验证

- 改动前 tsc 与全项目 ESLint quiet：分别 exit 0。
- 改动后 tsc、全项目 ESLint quiet、生产构建：分别 exit 0。quiet 并不表示已清零全部旧 warning。
- 全量测试：1675 passed、15 skipped，exit 0；最终助手层级调整后另跑相关 24 项测试，exit 0。
- 浏览器：8 个页面 × 6 组尺寸，共 48 组页面检查；修复前存在 12 组整页横溢，修复后 0 组，扫描还检查实际元素边界，避免只靠隐藏 body 溢出掩盖问题。
- 页面：首页、学习列表、成长记录、书架、阅读详情、笔记库、设置、人生伙伴。
- 尺寸：320×740、390×844、768×900、1024×768、1440×900、844×390。
- 三项模拟键盘测试：340px 可视高度下弹窗提交按钮、全局搜索、助手输入和关闭按钮可达；关闭操作通过。最终助手修复后对三项浮层测试另行复核。
- 截图已人工查看，包括窄屏笔记、1024px 设置、搜索与助手浮层。第一次截图揭示了助手顶栏遮挡，不能仅靠矩形边界检查认定全部交互通过。
