# 成长记录改版与复核 · 2026-11-16

本批直接修改网站，保留学习、阅读、人生伙伴与知识沉淀的核心。用户确认本次记录问题主要是显示、排版或点击；由于没有提供原始故障截图，以下为源码定位后实际修复并复核的场景，不宣称覆盖所有原始症状。

## 本批交付

- 成长页按“统计概览 → 学习日历 → 可筛选足迹 → 学习入口与回顾”组织，成长页不重复叠加学习页大标题。
- 日历格子由 11px 扩大至 28px；默认近 8 周，可切换 26 周，宽图仅局部滚动。提供图例、日期说明、键盘方向键与关闭后焦点恢复。
- 足迹按全部、学习验收、新掌握、对话筛选；每批加载 20 条，取消过去只显示前 40 条的死截断；空分类明确提示。
- 验收记录、知识点、对话均有来源链接；里程碑从微小装饰格改成可阅读并可点击的卡片，展示最近四项，更多通过足迹回看。
- 修复选中日期保存旧统计快照的问题；新记录到达时详情自动更新。强制跳过不计入日历的验收通过；目录骨架不计为掌握。
- 修复无计划或暂无 active 学习日时一律显示“全部完成”的错误；计划完成也注明跳过和通过分别统计。
- 长标题折行、摘要限行；教练回顾改为准确的“点击后生成”提示。展示改版不增加模型调用，不迁移旧数据。
