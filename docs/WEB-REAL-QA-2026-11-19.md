## 已修复的缺陷

- 首页刷新时能找回未完成的问题，继续回答复用原问题。停止旧问题后，可以直接发送新问题。
- 学习方向引导和学习日答疑展示生成阶段。未完成的问题会保存，可在刷新后继续。学习阶段标题兼容旧数据，避免重复出现阶段编号。资料标题中的 HTML 数字实体正常显示。
- 短篇自带材料的路线只使用提供的内容。迁移应用入口依据节点验收状态展示。
- 本地待同步的改动在刷新后仍受保护。正式版两台浏览器交错编辑时，云端拒绝较旧版本来覆盖新版，刷新后本地待同步内容仍可找回。相同快照重复到达时保留原云端版本。空文件夹进入云同步。
- 笔记库搜索直接展示命中项。关系链在正文滚动区域上方，点击关联笔记时用同页地址更新。侧栏和移动底栏提供笔记库直达入口。
- 长邮箱可留空昵称注册。新手引导只在首页自动启动。隐私政策和用户协议可在未登录时阅读。后台按页读取用户档案与云快照，每页按注册时间排序，加载失败可以重试。

## 涉及实际外部操作的范围

本轮测试账号和数据由验收专用。小程序按本轮要求暂缓。真实付款、外部邮件投递、正式反馈提交，以及改变其他用户或生产反馈的状态，未执行。备份已测试导出、导入和打开云端恢复确认。整本复盘已测试到结业入库，迁移应用的独立复验分支未完整走完。跨设备验收覆盖先后写入和刷新保留，同时到达服务端的写入还未压测。

## 11 月 19 日补测

补测发布版本为 `fa7816e`，腾讯云公开构建检查已核对。类型检查通过，自动测试 1718 项通过、15 项跳过。使用独立测试账号和线上模型。阅读测试使用通过设置导入的真实阅读记录，该记录的节点已由模型实际判分通过。

| 场景 | 实测结果 |
| --- | --- |
| 阅读迁移与独立复验 | 真实模型出迁移题，草稿刷新后仍在，提交获得「正确应用」。刷新后可从历史继续独立复验。模型换了场景出题，复验草稿刷新后仍在，提交后获得「独立迁移成功」。再次刷新可查看题目、作答、判定依据和模型反馈。390 像素宽布局无横向溢出。正式版的干净浏览器也能从云端重开复验结果。 |
| 两浏览器同时写入 | 基线版两个请求都成功，云端只剩一份。修后相同基线的两个真实浏览器同时保存时，云端只接受一个请求，另一个收到明确的冲突反馈。被拒绝的一端刷新后仍能看见本机改动。 |
| 大快照并发 | 用独立测试账号将快照扩大到分块存储，再并发写入。只有一个请求成功，云端笔记正文完整读回。测试结束后将该账号快照恢复至原体积。 |
| 断开和重连 | 浏览器阻断同步请求期间继续编辑，刷新仍能看到本机改动。恢复连接后同步到云端，干净浏览器可读取。 |
| 离线期间另一端更新 | 恢复连接后显示冲突，云端与本机各保留一份。刷新后可下载包含本机改动的备份，390 像素宽的提示完整显示，可直接打开数据设置。 |
| 云端已收到，浏览器未收到回执 | 延迟第一笔真实同步回执，输入第二笔改动后立即刷新。浏览器识别第一笔属于当前页面，补传第二笔，两份改动都能从云端读回。复验结果也已重新用线上模型判分并确认写入云端。 |
| 登录探测中断 | 阻断第一次会话检查后停留在原链接，点击重试后使用实际会话进入原页，链接参数仍在。 |

并发修复使用当前线上 D1 的条件写。分块快照的版本校验和写入使用同一批数据库事务，并保留原有存储格式。 [Cloudflare D1 批量事务说明](https://developers.cloudflare.com/d1/observability/find-expensive-queries/)
