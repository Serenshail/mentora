## 2. 用例明细

### RM-01 详细讲解（AQ-01 / AQ-02）

- **输入：** `详细讲解这段代码，逐行说清楚每一行在做什么、为什么这么写：\n\nint *rotate(int *nums, int n, int k) { int *arr = malloc(n*sizeof(int)); for (int i=0;i<n;i++) arr[(i+k)%n]=nums[i]; return arr; }`
- **期望：** 逐行/逐块解释 + 关键表达式到操作符级（`%n` 的循环语义）+ 至少一个具体输入的执行推演 + 指出至少 1 个边界问题（如 `k` 为负、内存释放）+ 复杂度
- **禁止：** 只给结论不解释；编造不存在的行；套用与代码无关的模板章节
- **判据：** `deep.block` + `deep.trace` + `deep.flaws` + `deep.complexity` 四标记全中；`clean.noMeta`

### RM-02 追问（AQ-05）

- **输入（承接 RM-01）：** `你上面说 %n 处理了循环，那如果 k 大于 n 呢？负数呢？`
- **期望：** 明确指出 `k % n` 对 `k>n` 成立；对负数在 C 中结果为负需修正（`((k%n)+n)%n`）；给出修正代码
- **禁止：** 重复上一轮全部内容；答非所问
- **判据：** 文本含 `k % n` 或等价表述 + 提及负数问题 + 给出修正

### RM-03 / RM-04 线性代数两轮（产品决定 §2）

**RM-03（a 轮）**
- **输入：** `我想学线性代数。`
- **期望：** 问 1–2 个关键问题（用途：机器学习/考研/数学系；基础）；**不创建目标**（增量 goals=0）
- **判据：** `clarifyRelevant` + `noInterrogate`（非问卷式）+ `noFabricate` + `noPrematureCreate`

**RM-04（b 轮，固定输入）**
- **输入：** `我会 Python 和一点高数，学线性代数是为了看懂机器学习论文里的公式，每天能投入 1.5 小时，请按这些信息建立学习目标。`
- **期望：** 创建目标（增量 goals=1）；`background` 含「Python」「高数」「机器学习」「1.5」；不再重复问用途/基础/时间；返回 `/learn/new?goal=` 入口
- **判据：** `created` + `backgroundSaved`（四个关键点全含）+ `noReAsk` + `hasEntry`

### RM-05 / RM-06 Rust 两轮

**RM-05：** `我想系统学 Rust。` → 同 RM-03 判据
**RM-06：** `我会 Python，想用 Rust 写命令行工具，每周 3 小时，请按这些信息建立学习目标。` → 同 RM-04 判据（关键点：Python / 命令行 / 3 小时）

### RM-07 加书（R02 / 搜索链路修复验证）

- **输入：** `把《思考，快与慢》加进我的书架，我想深入读。`
- **期望：** 调用 `add_book`；核查通过（查询为书名单 token）；书架增量 books=1；返回章节数与阅读入口
- **禁止：** 只说「书架是空的」不调工具；编造目录
- **判据：** 工具标签含「加书上架」+ 增量 books=1 + 返回章节列表

### RM-08 加书（已有同书）

- **初态：** 书架已有《影响力》
- **输入：** `帮我好好读一遍《影响力》。`
- **期望：** 识别已有该书，走接续/恢复而非重复添加；books 增量为 0
- **判据：** 不重复创建 + 提及已有/继续

### RM-09 学习计划修改（AG-02/AG-03）

- **初态：** 3 阶段计划，第 1 阶段有 1 个已完成天
- **输入（a 轮）：** `我每周只能学 3 小时了，把第二、三阶段调整一下，保留已完成的内容。`
- **期望：** 展示**具体新旧差异**（阶段名/天数/保留项），未直接写入
- **判据：** 审批卡预览含「原：」「新：」「保留」；执行前 planHistory 未增
- **b 轮：** `就按这个方案改。` → 执行后阶段变更、已完成天保留、planHistory 增 1

### RM-10 圆桌讨论（C03）

- **初态：** 3 席圆桌（naval/jobs/taleb），已有议题
- **输入：** `继续上次的讨论，重点讨论实施风险。`
- **期望：** 定位会话 → 带入原议题 + 新约束 → 三席独立发言 → 主持纪要（共识/分歧/条件化建议）
- **判据：** 三席发言都非空 + 纪要含「共识」「分歧」 + 结果写回原会话
