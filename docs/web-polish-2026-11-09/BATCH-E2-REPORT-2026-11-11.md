## 2. 学习列表

- **「正在学习」置顶卡**：当前项目 + 当前任务 + 进度摘要 + 醒目「继续学习」按钮（进入即知道学什么、点哪里）。
- **进度语义分列**（验收 2）：卡片与置顶卡都改为 `完成 N · 跳过 N · 掌握 N / 共 M 天`，不再用单一百分比概括；圆环仅作视觉辅助。
- **掌握口径**：只认知识点 `masteryStatus` 达 guided 以上（有学习证据），不把「读完/跳过」算掌握。

## 3. 学习详情

- **当前阶段条**（新增，主区域顶部）：`当前阶段 · 阶段名` + 当前任务标题 + 阶段目标 + 「完整路线」锚点跳转。
- **进度徽章分列**：已完成 / 已跳过 / 已掌握 / 共 N 天，四个独立徽章。
- **日程投影降为次要**：原为常驻卡片，改为默认折叠 `<details>`（有截止日期才展开）。
- 完整路线在下方 `PlanTimeline`（`id="plan-timeline"` 可锚点定位）；重排/历史恢复入口沿用既有实现。

## 4. 人生伙伴

- **当前会话上下文条**（新增）：会话标题 + 议题（首条用户消息，两行截断）+ 与会人物徽章——进来即知道在讨论什么、有谁。
- **发言与总结区分**：席位发言 `**【名字】**` 前缀 + 主持纪要 `## 圆桌纪要` 前缀（既有）+ 纪要卡 accent 底色（既有）；正文统一 16px。
- **失败态不只靠颜色**：失败席位加 ✕ 图标 + 「发言失败」文字；重试横幅改为「**XX、YY 发言失败；N 席发言已保留（原因）**」——明确谁失败、保留了什么、可重试什么。
- **深链**：`?session=<id>` 直达；指向不存在会话时显示明确提示条（含「知道了」关闭），不静默回退。
- 窄屏：对话记录默认折叠为横条（既有），阵容/议题在上下文条常显。

## 6. 走查中发现并修正的问题

**产品问题（2 个）：**
1. 学习列表无「继续学习」主入口、进度只有单一百分比 → 已加置顶卡与语义分列。
2. 人生伙伴无会话上下文条（议题/阵容要翻历史才看到）→ 已加常显条。

**走查脚本问题（3 个，非产品）：**
1. 仅写 localStorage 注入种子 → store `skipHydration` 导致内存态不更新，页面空骨架 → 改双通道（localStorage + dev 钩子 setState）。
2. 截图早于水合 → 加 `waitHydrated`（等 store 有数据且预期文本出现）。
3. 走查中途会话失效被踢登录页 → 加 `gotoAuthed`（检测 /login 后重登重试）。
