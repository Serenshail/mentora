# 网站 UI 与布局修复 · 2026-11-15

本轮接续现有实现，未重置工作区、安装或升级依赖、提交或部署。仓库原本已有大量未提交修改，当前 Git diff 包含前序工作，不能把整份 diff 当成本轮变更。

## 修改范围

- 首页：重排空态标题和建议入口；将过时的“最新 Next.js 15”建议替换成学习任务；中等宽度保留单栏，到 1280px 才展示右侧工作台。
- 对话：单行输入改为自动增高的多行输入，最高 160px；Enter 发送、Shift+Enter 换行；保留中文输入法与运行中草稿的发送守卫。用户消息保留换行，长连续字符可折行。修复输入框边框高度导致空输入也出现滚动条的问题。
- 工作台弹层：复用共享 Modal，支持焦点约束、Esc 关闭和关闭后返回入口焦点。
- 通用页头：手机上标题与操作纵向排列，图标不压缩，长标题可折行；正文、图片、表格、代码块约束在容器内。
- 全站框架：去除侧栏 sticky 与 relative 的冲突；搜索按钮占满侧栏可用宽度；手机顶栏补充搜索；底栏使用完整安全区留白。
- 导航：集中路由匹配规则，按路径段判断；/life 不再同时匹配学习；桌面与手机入口标注当前页。既有 /life → /learn?tab=life 跳转保持，跳转后的父级导航仍选“学习”。
- 学习标签：将标签状态直接绑定 URL，切换更新查询参数；刷新、同页导航与直达链接一致；保留其他查询参数。补上选中语义，320px 下三个入口保持单行。
