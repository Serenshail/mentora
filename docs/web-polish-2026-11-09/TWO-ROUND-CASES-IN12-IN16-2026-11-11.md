## 2. 检查项与判定

### 2.1 首轮（a 轮）——「合理澄清」，不等于交接完成

| 检查项 | 通过条件 | 对应产品决定 |
|---|---|---|
| clarify.relevant | 问了影响路线的关键缺失信息（用途/基础/时间，问 1–2 个最必要的） | §1 行 2 |
| clarify.noRepeat | 不重复问已知信息（初态为空，无已知可重复） | §1 行 2 |
| clarify.noInterrogate | **非问卷式**：连续 3 个以上编号问句判负（沿用 API 判据口径） | §1 |
| clarify.noFabricate | 未把猜测写成既知用户事实（不得出现「你是做 X 的」类断言） | §1 行 5 注 |
| clarify.noPrematureCreate | 首轮默认不创建目标（**增量** goals=0） | §1 行 2 |
| clean.noLeak | 无内部协议泄漏 | 通用 |
| clean.notTruncated | 未截断（结构性判据） | 通用 |

**首轮结果独立统计为「澄清合格」，不计入交接完成率。**

### 2.2 二轮（b 轮）——「真实交接」

| 检查项 | 通过条件 | 对应产品决定 |
|---|---|---|
| handoff.created | **增量** goals = 1（对象真实创建，不是只有工具卡） | §1 行 3 |
| handoff.backgroundSaved | 新目标 `background` 字段包含本轮提供的用途/基础/时间要点；**不得编造未提供的内容** | §1 行 3 + 「background 非空 ≠ 正确」注 |
| handoff.noRe-ask | 不再询问已提供的用途/基础/时间 | §1 行 3 |
| handoff.entry | 返回接续入口（/learn/new?goal=…） | §1 行 3 |
| handoff.noDup | 重复执行不产生第二个目标（重放保护） | §4 动作纪律 |
| clean.noLeak / notTruncated | 同首轮 | 通用 |

**背景校验的判定材料：** 从 dev 钩子读取真实 `goal.background` 字段 + 交接 transcript，与固定输入逐项对照；不凭模型文案判定。

### 2.3 统计口径

- 首轮合格率、二轮完成率**分别报告**。
- 整批观察通过率与条件通过率（排除有证据的上游故障）**同时报告**。
- 上游故障必须附错误日志摘录才能归类。
