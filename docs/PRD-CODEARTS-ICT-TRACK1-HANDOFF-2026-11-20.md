## 4. 分阶段执行

### 阶段 A 版本与基线

1. 固定源码快照与依赖信息，记录当前分支、提交号、工作区变更清单和快照摘要。不要把旧提交号等同于包含所有未提交修改的参赛版本。
2. 在隔离位置执行类型检查、相关测试、构建。记录命令、结果、退出码与既有失败。审查部署、模型通道、同步、首页智能体及演示入口是否可用。
3. 盘点 docs/CODEARTS-PRACTICE.md、.codeartsdoer/specs/huawei_cloud_upgrade/、git 记录和已有脱敏日志，建立历史码道参与及华为云成果索引，区分历史版本和本轮实际成果。

### 阶段 B 代码与回归

1. 完成第 3 节的 RDS 同步修复。新增针对实际行为的测试，至少覆盖并发胜负、空值首次写入、冲突失败不删除数据、写入清理事务失败及既有调用兼容。优先使用可控 PostgreSQL 实例进行集成测试，测试数据使用专门库或可靠隔离命名空间。
2. 验证 D1 同步回归、客户端冲突保留和现有相关业务测试。运行类型检查与构建。测试需体现响应和数据库最终状态，不能仅检查源码字符串。
3. 在码道工作记录中保留真实的需求理解、代码变更、测试、问题定位和修复过程，以及对应文件、差异和日志。只记录实际执行结果，避免将 Codex 的初步修改描述为码道生成。

### 阶段 C 华为云接入与部署

1. 核对当前资源、区域、权限和现有云资产。优先复用已确认独立的 RDS、DCS 及计算环境。使用独立演示账号与合成数据，隔离测试进程、数据库和缓存。需要新建资源时先核对计费方式、可用额度和预算。受条件限制时继续完成构建与可复现部署准备。
2. 通过码道及实际可用的 Skills 实施资源关联、构建和部署，记录工具名称、参数的非敏感摘要、资源状态及对应结果。构建当前代码镜像，记录源码标识、镜像摘要、部署配置，推送 SWR 并部署至可用 ECS 或 CCE。提供可访问的 HTTPS 演示入口。
3. 使用实际 RDS 和 DCS 验证隔离、存储持久化、缓存跨进程行为及并发同步。配置并测试 ModelArts MaaS 的真实流式对话、结构化输出和首页工具调用，记录具体模型、环境和失败情况。健康检查只能证明配置与服务响应，须做实际业务操作。
4. 核验服务重启后的数据、日志、故障提示、回滚和演示窗口。不要将生产数据或现有腾讯云服务迁往测试资源。密钥只通过安全配置注入，脱敏保存记录。

### 阶段 D 作品演示与材料

1. 围绕一个具体学习目标，真实走通目标澄清、计划、学习、验收、提出调整、查看差异与批准、保留已完成内容、笔记沉淀和复习。覆盖拒绝审批及中断恢复，记录视频和前后状态。页面或流程未实现时先修复，不能依靠预制回答充当真实模型与工具调用。
2. 按参赛信息表填写可证实内容，保留字数限制。学校、队伍、成员、联系方式和合照缺失时留空。技术实践部分明确区分历史码道工作与本轮工作，写清华为云资源实际用途和验证状态。
3. 生成架构图、演示说明、视频与源码复现说明。量化结果使用实际样本及测量方法，不虚构学习效果或性能。需要真实用户测试时准备可复用的任务脚本及记录表，参与者不足如实留待补充。正式提交及上传依据用户和赛事系统的安排执行。
