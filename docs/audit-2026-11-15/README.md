## 结论与优先级

工具层通过，业务层仍有高优先级风险。本轮修复 9 类具体问题，其中流式回答、远端数据库响应和同步上传的资源边界由运行时测试验证。跨设备写入的原子性、并发配额计量尚未修复，不能认定“系统连贯性已全部达标”。

### 优先处理的遗留问题

| 编号 / 级别 | 位置 | 具体触发与影响 | 建议与验收方式 |
| --- | --- | --- | --- |
| R01 · P1 | `src/app/api/sync/route.ts:218`、`:236`；`src/lib/auth-client.ts:326` | 服务端先读取并比较 `baseVersion`，随后仍使用 `overwriteOnConflict: true`。两个请求读取同一版本后均可覆盖成功；Web 推送序列化的内容只有 `{data: localData()}`，没有把版本约束接入请求。这不是原子条件写。现有源码测试确认了“有条件 UPDATE 能力”和“有 409 分支”，不能证明实际同步路径用了它。 | 统一 Web/小程序版本令牌，按存储通道实施原子 CAS；旧客户端迁移策略单独定义。验收：两个设备从相同基线同时编辑，必须一方成功、一方冲突；冲突方保留本地内容并可比较恢复。不得靠先 GET 再比较代替原子写。 |
| R02 · P1 | `src/lib/server/usage.ts:82`、`:96`；`src/lib/server/quota.ts:54`、`:67` | 用量及次数均是读旧值再整条覆盖。并发读到同一个值后，N 次计费请求可能只记入一次增量。数据库熔断时又会按既有策略放行或跳过计量。注释所说“误差一两次”没有并发上界保证。 | 原子增量与预算预留/结算；同时明确故障放行的成本上限。用 30 个并发请求验证累计值，不以单请求测试替代。此处涉及多通道计量方案，本轮没有以单进程锁冒充跨实例修复。 |
| R03 · P2 | `src/lib/auth-client.ts:180`、`:615` | 认证探测成功后调用一次 `bootSync()`，自动推送 effect 启动时又调用一次；二者没有同账户在途合并。首屏可能重复读取完整云快照，并分别进入同步判定。 | 按账户合并在途首轮同步，验证并发启动只产生一次拉取；账户切换和失败重试应保持隔离。 |
| R04 · P2 | `src/components/feedback-widget.tsx:48`；`src/app/api/feedback/route.ts:55` | 客户端超时会进入重试队列，但服务端 GitHub 创建 Issue 没有请求幂等标识，也未绑定客户端中止。Issue 已创建而客户端未收到确认时，再次重试可能创建重复反馈。新增客户端等待上限只解决等待状态，不等于解决幂等性。 | 增加稳定反馈 ID 和服务端去重记录；“创建成功但确认丢失”测试中必须只有一个 Issue。 |
| R05 · P2 | `src/lib/server/db.ts` 的 `upstashList` / `dcsList` | SCAN 限定 60 轮后直接返回已收集结果，没有标注游标尚未结束；键空间较大或匹配稀疏时，调用方可能把部分列表当完整列表。循环是有界的，但业务结果可能不完整。 | 返回明确的不完整状态或可续游标；模拟第 60 轮游标仍非 0，不能伪装成完整空库/完整清单。 |
| R06 · P2 | `src/app/api/cron/weekly-digest/route.ts` | 分块并发限制了瞬时并发，但仍遍历全量用户；没有总作业游标或每用户本周去重记录。数据量增长或慢依赖下可能超过 60 秒，重跑可能重复发送已完成部分。 | 作业分页、进度检查点、每用户周期幂等键；以超时后续跑验证不重发、不漏发。 |

上述事项是具体源码路径支持的风险；没有对真实云端实施并发写入、发送邮件或创建 Issue 的破坏性验证。

| 编号 | 原问题 | 实现与验证 |

| A03 · P2 | 客户端收到错误事件后抛错但未取消读取器；成功后锁也未释放 | streamChat 使用 finally 取消/释放。新增两项运行时测试在修复前均失败，修复后通过 |

| A05 · P1 | 同步 JSON/gzip 分支先完整 text/arrayBuffer 再检查大小；chunked 超大包可先占满内存 | 改为流式累计字节，超限即取消并返回 413；既有解压输出上限保留。2 项运行时测试证明提前停止且不写数据库 |
| A06 · P2 | 圆桌 session 参数只影响 state 初值，同页切换参数或云端迟到水合不再定位目标 | 使用 useSearchParams + Suspense；在目标数据到达后应用，每个目标只应用一次；真正切会话时停止旧流。类型、全量测试、生产构建通过；同页导航与迟到水合的浏览器专项尚未补验 |
