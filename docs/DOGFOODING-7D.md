# Founder 7 天自用记录（Gate 0 证据表）

> 目的：在写任何主智能体代码之前，先用**当前产品**回答一个问题——我自己会不会天天打开它。
> 规则：只用真实任务，不做演示；不美化记录；失败比成功更有价值。
> 判定标准见 [`ACCEPTANCE-FOUNDER-FIRST-2026-10-24.md`](ACCEPTANCE-FOUNDER-FIRST-2026-10-24.md) 的 Gate 0。

---

## 每天怎么记（每条约 1 分钟）

只记四件事：**我想干什么、我去了哪、花了多久、留下了什么**。

| 日期 | 我真实想干的事（原话） | 我从哪进去的 | 耗时 | 最后留下了什么 | 绕路 | 便利度 | 明天还想开吗 |
|---|---|---|---|---|---|---|---|
| 10-25 | 例：想搞懂 React 的闭包为什么会导致 stale state | 侧栏→学习教练 | 12 分 | 1 篇笔记 + 1 个待复习 | 是（先找了 2 分钟入口） | 3 | 会 |
| 10-25 | | | | | | | |

字段口径：

- **从哪进去的**：侧栏 / 首页卡片 / ⌘K / 左下助手 / 直接输 URL。记下来是为了看“入口”到底有没有问题。
- **耗时**：从产生念头到拿到结果，含找入口和犹豫的时间。
- **留下了什么**：目标 / 笔记 / 洞见 / 复习项 / 决策 / 什么都没有。“什么都没有”要如实写。
- **绕路**：是否中途去了别的页面、复制粘贴、重新解释同一件事。
- **便利度**：1–5，5 = 不需要想就知道点哪。
- **明天还想开吗**：会 / 不会 / 看情况。

---

## 建议的 5 个真实任务（不用凑满，遇到就记）

1. 今天真的想学的一个东西（哪怕只是搞懂一个小概念）。
2. 一段你刚看到、想留下的内容（文章/聊天/代码片段）。
3. 一次真实的复习冲动：“这条我好像快忘了。”
4. 一本你正在读或想读的书，问它一个具体问题。
5. 一个你真实在纠结的决定（工作/学习方向/要不要做某件事）。

---

## 第 7 天只回答三个问题

1. 这 7 天里，我有几天是**主动**打开它的？（不是被任务逼的）
2. 有没有哪一次，它比我自己去翻笔记、搜网页更快？
3. 如果明天它消失了，我会不会觉得少了点什么？

三个问题里有两个“否”，就不要写主智能体代码，先修入口和结果链。

---

## 停止线（出现即停，不要继续加功能）

- 每次都要先想“这个功能在哪”；
- 说完话还要自己去别的页面搬内容；
- 便利度中位数低于 4；
- 连续两次它理解错了你想干什么；
- 用完没有留下任何能复用的东西；
- 第 7 天不想再打开。

---

## 记录完之后

- 通过：进入 PR 1（Agent 类型、意图 schema、ActionEnvelope、黄金测试集），我可以直接开工。
- 不通过：把记录表里“绕路”和“便利度低”的行挑出来，那些就是下一轮唯一要修的东西——不是加功能，是修路径。
